# Event Structure Cosmology (QG-088)

Is the true cosmological degree of freedom the evolving STRUCTURE of a causal-information
network, from which space, time and expansion emerge?

## The structural formalism
Define structural variables S(t) (connectivity, complexity, causal density, network
dimension) and an evolution law H_S = d ln(S)/dt. For any S ∝ a^p, H_S = p·H.

## Result: no structural quantity evolves like H
| structural variable | scaling | p = H_S/H |
|---|---|---|
| node count N | a³ (4-volume) | 3 |
| link count E | a³ | 3 |
| average degree k̄ | const | 0 |
| clustering C | N^-3/4 = a^-9/4 | −2.25 |
| path length L | ln a | ~0 |
| network dimension d | const (d=4) | 0 |
| causal density ρ_c | const | 0 |
| **scale factor S = a** | **a** | **1 ← matches H** |

Only S = a gives H_S = H. Node/link count give 3H; degree/dimension/causal density give 0;
clustering gives −2.25H.

## Redshift and a₀
- Redshift 1+z = S_obs/S_emit = (1+z)^p: only p = 1 reproduces the observed 1+z; p = 3
  (node count) gives (1+z)³, excluded.
- a₀ = c·d ln(S)/dt = c·p·H: all give a₀ ~ cH (or 3cH), the 'cH class' (no 1/2π).

## Verdict
Level 1 passes; Levels 2–4 fail/partial; Level 5 fails. The causal-information network
picture is rich but observationally equivalent to FLRW (or falsified) — structure is another
clock (consistent with QG-080–087). The true degree of freedom is NOT structure.
