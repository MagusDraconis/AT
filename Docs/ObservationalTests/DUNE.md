## 8. Hostile Audit

*Assuming AT is wrong: what would DUNE most likely reveal?*

DUNE could reveal that neutrino CP violation is absent (δ_CP = 0 or π) — which would challenge AT's claim that O(1) CP violation arises naturally from defect moduli space geometry. This wouldn't kill the framework (the geometry argument is heuristic), but it would eliminate one of its distinctive neutrino predictions.

More dangerous: if DUNE + JUNO confirm inverted ordering at >5σ, and Hyper-K confirms, AT would need to develop a fundamentally different neutrino defect model. The attractive self-interaction argument (λ > 0 in φ⁴) would be wrong.

Proton decay detection would neither support nor falsify AT — the framework does not require proton decay. However, if proton decay is observed at a rate consistent with minimal SU(5) GUTs, this would support GUT unification, which AT's defect ecology analysis (X056) argues against. AT would need to explain why the observed decay rate does not imply the full GUT gauge structure.
