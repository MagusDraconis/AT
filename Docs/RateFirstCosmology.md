# Rate-First Cosmology (QG-089)

Is the true cosmological degree of freedom a fundamental cosmic rate R, from which time,
expansion and a₀ emerge?

## The formalism
Assume R(t) is fundamental; time t = ∫ dR⁻¹; scale factor a = exp(∫ R dt); redshift
1+z = exp(∫ R dt); a₀ = c·R.

## The tautology
A rate is a rate of something WITH RESPECT TO time. R(t) = H(t) = d ln a/dt already requires t.
"Time emerges from the rate" inverts the definition N = ∫ R dt — it is circular.

## Information content
H and a are bijective: a(t) = exp(∫ H dt) and H = d ln a/dt (up to a(0)=1). H carries no more
information than a(t) or t. "Rate-first" is FLRW with H as the given function.

## Redshift and a₀
- Redshift 1+z = exp(∫ R dt) = a_obs/a_emit — identical to FLRW.
- a₀ = c·R: for R = H this is cH = 6.5e-10 (the 'cH class', no 2π); for R = H/2π it is
  cH/2π = 1.04e-10 (the angular-frequency rate). The same cH vs cH/2π ambiguity as QG-084/085.

## Verdict
Level 1 passes; Levels 2–3 pass but tautological/equivalent; Level 4 partial (a₀=cH, no 2π);
Level 5 fails. Rate-first is FLRW with H as the given function — no new physics or prediction.
