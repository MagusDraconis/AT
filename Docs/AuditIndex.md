# Audit Index

The catalogue of the audit programme: every ResearchY investigation with its **AuditNumber**, **Title**, **Status** and
**Location** (its own document followed by its xUnit suite). Generated mechanically from the repository on 2026-10-11;
links are relative to `Docs/`. The per-audit *narrative* — the project-memory entry for the era — lives in
`Archive/NewChat_Part2_Gravity.md` (G, E), `Archive/NewChat_Part3_QM.md` (QM) and `Archive/NewChat_Part4_QG.md` (QG),
and **each audit appears in detail exactly once**; the current state is `NewChat_Start.md` and the open problems
`NewChat_OpenProblems.md`.

**Identifier rule** (from the ResearchY index): every investigation receives a permanent identifier on creation;
numbers within a group are never reused. Groups are topics, not chronological order.

**The Status column** is extracted mechanically: the audit's own **verdict** token (`DERIVED`, `EMERGENT`, `BOUNDARY`,
`REFUTED`, `PARTIAL`, `GLOBAL INPUT`, `GAUGE-LIKE`, …) where its header states one, otherwise the project-memory verdict
for that era, and only then the lifecycle status (`COMPLETE`). A `COMPLETE` therefore means the doc states no verdict
token — the result is in the document's prose.
