# Derived Observables (QG-080)

| Observable | Weak TSC (γ=a) | Strong TSC (γ≠a, clocks faster in past) |
|---|---|---|
| Redshift | 1+z (matches ΛCDM) | 1+z but wrong sign convention |
| SN Ia time dilation | (1+z), b=+1 | 1/(1+z), b=−1 (EXCLUDED ~40σ) |
| Luminosity distance | χ(1+z) (matches) | χ (no (1+z) factor) |
| Angular diameter distance | χ/(1+z) (matches) | χ (shifted acoustic scale) |
| BAO / CMB θ* | unchanged | excluded |

Consistency with SN Ia time dilation, BAO and the CMB acoustic scale REQUIRES γ=a,
i.e. conformal-time FLRW. Any genuine deviation is observationally excluded.
