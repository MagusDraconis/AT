# AT Physical Correspondence

## Graph Laplacian = Tight-Binding Hamiltonian = Lattice Physics

### 1. The Mathematical Identity

For a 1D chain of N nodes, the graph Laplacian is:

L_ij = 2δ_ij - δ_i,j+1 - δ_i,j-1

The tight-binding Hamiltonian for electrons on a 1D chain is:

H_ij = ε·δ_ij - t·(δ_i,j+1 + δ_i,j-1)

With ε = 2t: **H ≡ t·L** (up to sign convention).

This is a **mathematical identity**, not an approximation or analogy.
The graph Laplacian and the tight-binding Hamiltonian are the same matrix.

### 2. Extensions to Higher Dimensions

- **2D Square**: L ↔ 2D tight-binding (s-band electrons)
- **2D Hexagonal**: L ↔ graphene tight-binding (Dirac cones at K)
- **3D Cubic**: L ↔ 3D tight-binding (simple cubic metal)

In every case, the correspondence is exact.
