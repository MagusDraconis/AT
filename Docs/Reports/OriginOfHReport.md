# Origin of H Report (QG-099)

What is the true status of H — derived, boundary condition, selection effect, or fundamental
constant?

## The answer: H is primitive
H cannot be calculated from {c, G, ħ, Λ, N} without circularity:

- **{c, G, ħ}**: only 1/t_P = c/l_P ≈ 1.85×10⁴³ s⁻¹ vs H0 ≈ 2.18×10⁻¹⁸ s⁻¹ — **61 decades off**.
  H is not a Planck-scale rate.
- **Λ**: H ~ c√Λ ≈ H0 (ratio ~1.4), but this is **circular** — Λ ~ H²/c² is itself H-dependent
  (causal set). "H from Λ" is "H from H".
- **N**: circular — N = (c/H·l_P)⁴ defines N *from* H.

The only non-circular relation is Λ ~ H² (explains Λ *from* H, not H *from* Λ).

## The dependency graph
```
H (scale-setting rate) — PRIMITIVE / boundary condition
  ├─► Λ ~ H²/c²   (genuine, causal set)
  └─► a₀ ~ cH     (order of magnitude, 2π coincidental)
```

H sits at the top: Λ and a₀ inherit their scale from H, but H is not inherited from anything
deeper.

## Verdict
Levels 1–4 pass (mapped, circularities identified, best explanation = boundary condition,
H primitive); Level 5 fails (no falsifiable route). H is the final primitive parameter of the
program — a boundary condition — with no deeper origin yet found.
