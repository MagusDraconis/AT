# AT-128: Autonomous Collective Wave Field

## Executive Summary

**Classification: C — Emergent Collective Field**

AT-128 determines whether the collective wave field Θ(x,t) becomes
an autonomous dynamical object at high charge density — predictable
without tracking individual charges. Closure tests across densities
ρ_Q ∈ [0.02, 1.0] confirm:

**Θ IS AN EMERGENT MACROSCOPIC FIELD.** At ρ_Q > 0.50, the collective
field can be predicted without individual charge information.

## 1. The Closure Question

Θ(x,t) = Σ A_c·exp(iθ_c) — defined as the sum of charge modes.
Is Θ merely a convenient sum, or does it become autonomous?

Closure test: predict Θ(t+Δt) from Θ(t) alone vs from all θ_c.
- Field error < particle error → Θ autonomous
- Field error ≈ particle error → Θ contains all info
- Field error ≫ particle error → individual charges matter

## 2. Results

24 runs: 6 densities × 2 layouts × 2 seeds.

| Metric | Value |
|--------|-------|
| Field autonomy | YES (at ρ_Q > 0.50) |
| Best equation | Wave (1st order) |
| Critical density | 0.50 |
| Closure crossover | ~0.30-0.50 |

## 4. Particle-Field Phase Diagram

- **ρ_Q < 0.3**: Particle regime — individual charges matter
- **0.3 < ρ_Q < 0.5**: Mixed regime — field gaining autonomy
- **ρ_Q > 0.5**: Field regime — Θ autonomous

## 5. Conclusion

At high density, the collective field Θ(x,t) becomes an autonomous
dynamical variable. Individual charge details become irrelevant
for macroscopic prediction — this is classical emergence of a
field degree of freedom from discrete constituents.

Θ describes PHASE dynamics. Q (topological charge) remains a
separate conserved quantity. Complete proto-matter description
requires both Q and Θ.
