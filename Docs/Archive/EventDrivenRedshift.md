# Event-Driven Redshift (QG-087)

Can redshift be rewritten as event-density evolution instead of metric expansion?

## Yes, trivially
Redshift is a frequency ratio 1+z = ν_emit/ν_obs. In an event-density framework with a
monotonic event count N(t), define 1+z = N_obs/N_emit. For N = a this is exactly the FLRW
redshift 1+z = a_obs/a_emit. Time dilation follows as (1+z) (the same ratio).

## But it is not independent
The identification 1+z = N_obs/N_emit is only observationally consistent when N ∝ a. A
physically motivated N (e.g. causal-set cardinality ∝ 4-volume, giving N ∝ a³) would predict
1+z = (N_obs/N_emit) = (a_obs/a_emit)³ = (1+z)³, i.e. a DIFFERENT redshift–distance relation,
which is excluded by the observed 1+z (and its time dilation).

So redshift CAN be phrased in event language, but the phrase is equivalent to "the event
count scales as the scale factor" — a reparametrization (QG-080/082), not a new derivation.
