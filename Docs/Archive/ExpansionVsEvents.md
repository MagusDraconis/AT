# Expansion vs Events (QG-087)

Is H = d ln(a)/dt or H = d ln(N_events)/dt?

## The mathematical fact
For any monotonic N(t), H_event = d ln(N)/dt is a valid "Hubble rate". The OBSERVED
H(z) = H0 √(Ωm(1+z)³ + ΩΛ) is reproduced if and only if d ln(N)/dt = H_ΛCDM(t), whose
unique solution is N(t) = a(t) (the ΛCDM scale factor). So:

- **N = a** : trivially equivalent to FLRW (another reparametrization).
- **N ≠ a** : predicts a different H(z) and is falsified.

## Why the simple event models fail
| model | H_event(z) | verdict |
|---|---|---|
| N ∝ t (linear/coasting) | (1+z)/t0 | ~5-17% match at z≤2, but NO acceleration → fails SN Ia + CMB |
| N ∝ tⁿ (power) | n(1+z)^(1/n)/t0 | coasting family, same failure |
| N ∝ e^λt (exponential/de Sitter) | λ (constant) | no matter era (H should rise ∝ (1+z)^(3/2)) |
| N ∝ ln t (saturation) | 1/(t ln t) | decays too fast |
| **N = a (FLRW)** | H_ΛCDM(z) | exact (by construction) |

The reconstruction fails precisely at the matter→de Sitter transition: only the ΛCDM
scale factor has the required H(t).

## a₀ from events
a₀ = c × d ln(N)/dt = c × H_event. All event models give a₀ ~ cH = 6.5e-10 m/s² (the "cH
class", no 1/(2π)) — the right order but missing the 2π factor (QG-084/085).

## Verdict
Levels 1–4 (partial); Level 5 fails. H = d ln(N)/dt is trivially true for N = a, but the
event interpretation adds no new physics. The only event model that works is N = a — another
clock, not an independent derivation. Expansion is NOT fundamentally replaced by event growth.
