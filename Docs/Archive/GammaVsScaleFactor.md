# Gamma vs Scale Factor (QG-082)

Is γ = a unique? Yes.

## Core relation
In static space with an evolving clock γ = dτ/dt, coordinate frequency is conserved, so
redshift and time dilation are the **same** quantity:

    1+z = γ_obs/γ_emit        (redshift)
    Δτ_obs/Δτ_emit = γ_obs/γ_emit   (time dilation)

With γ_obs = 1 this forces **γ(z) = 1/(1+z) = a(z)**. Time dilation (b = 1) is a redundant
but independent confirmation.

## Candidate families (each evaluated at z = 1)

| Family | z_model | b_eff | status |
|---|---|---|---|
| γ = a^0.5 | 0.41 | 0.50 | excluded (≫5σ) |
| γ = a^0.75 | 0.68 | 0.75 | excluded |
| **γ = a^1.0** | **1.00** | **1.00** | **viable (= FLRW)** |
| γ = a^1.25 | 1.38 | 1.25 | excluded |
| γ = a^1.5 | 1.83 | 1.50 | excluded |
| γ = a(1+εz), ε=±0.2 | ≠1 | ≠1 | excluded |
| γ = a·exp(βz), β=±0.2 | ≠1 | ≠1 | excluded |
| γ = a/(1+αz), α=±0.2 | ≠1 | ≠1 | excluded |

The power-law family γ=a^p predicts b = p exactly, so SN Ia (b = 1.00±0.05) alone force
p = 1.00±0.05, and the redshift measurement (far more precise) forces p = 1 exactly.

## Consequence for g†
g† = c·d(ln γ)/dt/2π = f·cH/2π with f = a·γ'/γ. Only γ = a survives (f = 1), so
**g† = cH/2π is forced** — any γ ≠ a would give g† = f·cH/2π and is excluded.

## Conclusion
γ = a is not an arbitrary encoding of FLRW; it is uniquely selected by the redshift (and,
redundantly, time-dilation) observations. No deeper clock dynamics can remain distinct.
