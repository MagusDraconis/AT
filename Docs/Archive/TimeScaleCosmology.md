# Time-Scale Cosmology (QG-080)

Reinterprets cosmic expansion as the evolution of physical time τ (clock rate γ=dτ/dt), with static comoving space. With γ(t)=a(t), τ is conformal time and the model is FLRW in conformal coordinates — observationally equivalent to ΛCDM. See TimeScaleEquations.md for the derivations; Predictions.md for the falsifiability verdict.
