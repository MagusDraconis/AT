# Unified Emergent Scale Report (QG-098)

Can Λ ~ 1/√N and a₀ ~ O(cH) both be understood as consequences of a single emergent cosmic
rate generated by causal discreteness?

## The circularity
N = (R_H/l_P)⁴ with R_H = c/H. So H is the INPUT that defines N — H is NOT derived from N.
To get a rate from N alone, one must divide by a time scale, and the only natural time is 1/H
— which is H again. So the "rate from N" is circular.

## What emerges
Given H as input:
- Λ = 1/√N/l_P² = H²/c² (the 'why now' coincidence).
- a₀ = cH (order of magnitude).

Both are projections of the SAME input rate H: Λ is its square, a₀ is its linear projection.

## Verdict
Levels 2–3 pass (Λ recovered, a₀ at order of magnitude); Level 1 fails (H not emergent);
Level 4 partial (single INPUT rate, not emergent); Level 5 fails.

The "single cosmic rate" is the OBSERVED H, re-expressing Λ and a₀ as its square and linear
projections. This is a compact notation, not a deeper theory: H itself must be put in, and no
distinct prediction emerges.
