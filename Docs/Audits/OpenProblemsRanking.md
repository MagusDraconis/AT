## 4. Conclusion

The ranking separates TQM's **own** unresolved nodes from TRM's **candidate**
modules. **Koide origin** is Priority 1 — it is the deepest single gap (the $45^\circ$
origin is the last unexplained dimensionless number, with a proven no-go that it cannot
be derived without a new primitive). **m=3 closure** is Priority 2 — the highest-value
*candidate* for the $N\le3$ upper bound that Phase 151 left open, testable in principle
but currently unmapped. **Shared cascade** is Priority 3 (abundance-law structure,
untestable without a new primitive). The remaining TRM modules (Frame dragging, Memory
channel, Theta chain, Unified action) rank lower: testable-but-risky, niche, homonymous,
and premature respectively. This ranking is consistent with the earlier TRM
prioritization (m=3 first) and extends it to include TQM's own gaps.
