# TQM (THE Q-MODEL) Revision Protocol

## Evidence-Based Modification, Preservation, and Retirement Procedures

*TQM Collaboration — Governance Document, August 2026*

---

## 1. Purpose

### 1.1 Why a Revision Protocol

Scientific frameworks that lack pre-defined revision procedures risk post-hoc rationalization. When data arrives, proponents may be tempted to adjust the framework to fit the data without acknowledging that a prediction has failed. This document exists to prevent that.

The revision protocol defines, before key experimental results become available, exactly what actions follow from what evidence. It applies equally whether the framework's predictions succeed or fail.

### 1.2 Distinctions

This protocol distinguishes three levels of response:

| Response | Definition | Example |
|----------|------------|---------|
| **Revision** | A specific model or sub-component is modified or replaced. The broader sector and all higher dependency tiers survive unchanged. | Replacing the neutrino defect model (Model A) with an alternative defect potential. |
| **Replacement** | An entire sector (set of related predictions and derivations) is abandoned and a new approach is developed. Higher dependency tiers survive. | Replacing the cosmology sector (Λ(t) derivation, Tier 4) while preserving quantum mechanics and particle physics (Tier 0-2). |
| **Retirement** | The framework as a whole is abandoned. Salvageable mathematical or conceptual results may be preserved as standalone contributions. | Internal logical contradiction demonstrated in Tier 1 derivations; or cumulative failure of all testable predictions. |

### 1.3 Guiding Principles

1. **Pre-commitment.** This protocol is published before the relevant experimental results. No retroactive modifications to existing commitments are permitted.

2. **Modularity.** The framework is tiered. Failure at one tier does not necessarily imply failure at higher tiers. The protocol respects this structure.

3. **Cumulative evidence.** Isolated tensions (1–2σ) do not trigger revision. Only statistically significant contradictions or cumulative failures across independent sectors trigger action.

4. **Transparency.** All revisions must be publicly documented. The revision history is part of the framework's scientific record.

5. **Competitive comparison.** If a competing framework explains the same data with fewer primitives or simpler assumptions, TQM should be retired regardless of its internal consistency.

## 3. Evidence Classification

### 3.1 Significance Levels

Evidence against a prediction is classified into four levels. Action is triggered only at Level C or above for isolated predictions, or cumulative Level B across multiple independent predictions within the same sector.

| Level | Name | Statistical Threshold | Description |
|:--:|------|:--:|-------------|
| **A** | Suggestive | ~1–2σ | Tension noted. No action required. Continue data collection. |
| **B** | Significant tension | ~2–3σ | Investigate systematic errors. If persistent across independent experiments, prepare contingency revisions. |
| **C** | Strong contradiction | >3σ | Trigger revision of the specific model or prediction. If the prediction is unique to TQM, this constitutes falsification of that component. |
| **D** | Decisive falsification | >5σ | The prediction is falsified. The corresponding model or sector must be replaced or abandoned. No further defense of the original claim is permitted. |

### 3.2 Combined Evidence

Multiple independent predictions within the same sector showing Level B tension cumulatively constitute Level C evidence against that sector. Decision: Sector Replacement.

### 3.3 Theoretical Evidence

A logical error in a derivation, demonstrated by independent researchers and confirmed by the collaboration, constitutes Level D evidence regardless of experimental status. Action depends on which tier the error affects.

## 4. Revision Rules

### 4.1 Action Matrix

| Evidence Level | Isolated Prediction | Multiple Predictions (Same Sector) | Affects Tier 0-1 |
|:--:|---------------------|-----------------------------------|------------------|
| **A** (1–2σ) | No action | No action | No action |
| **B** (2–3σ) | Monitor | Prepare contingency | Investigate |
| **C** (>3σ) | **Model Update** | **Sector Replacement** | **Emergency review** |
| **D** (>5σ) | **Model Update** (if isolated) | **Sector Replacement** | **Framework Retirement** (if Tier 1 affected) |

### 4.2 Escalation Rules

1. A single Level C contradiction triggers Model Update for the affected prediction only.
2. Two or more Level C contradictions within the same sector trigger Sector Replacement.
3. Level D contradiction in Tier 1 triggers an emergency review. If the contradiction is confirmed by independent researchers, the framework may be retired.
4. Cumulative Level B evidence across three or more independent sectors triggers a comprehensive review of the entire framework.
5. Discovery of a competing framework with fewer primitives that makes equal or better predictions triggers retirement regardless of TQM's internal consistency (Occam's razor).

## 5. Cosmology Revision Protocol

### 5.1 The Core Prediction

The framework predicts w(z) ≠ −1, with w(z) ≈ −1 + 0.015·(1+z)^(3/2). This depends on Λ(t) = α/√V(t) (X046). The decisive experiment is Euclid (ESA, 2024+), with σ(w) ≈ 0.02, improving to σ(w) ≈ 0.01 with Roman (2027+).

### 5.2 Case: w(z) = −1.000 ± 0.01 (Level D)

**Action: Sector Replacement.**

The Λ(t) hypothesis is falsified at >3σ. The following specific actions are required:

1. **Abandon** the Λ(t) = α/√V(t) model (X046).
2. **Abandon** the specific w(z) ≠ −1 prediction (P1) and the a₀ ≈ cH₀ derivation (P2) in their current forms.
3. **Retain** Tier 0-3 (core, structural, identity, abundance framework as conceptual structure).
4. **Evaluate** recovery paths as defined in Section 12.1 of the Failure Analysis Framework document:
   - Path A: Constant Λ, modified abundance.
   - Path B: Freezeout independent of Λ.
   - Path C: Alternative dark energy emergence.
   - Path D: Full cosmology sector replacement.
5. **Within 24 months** of decisive falsification, publish a revised cosmology sector or formally declare Tier 4 cosmology as an open problem within the framework.

**What survives:** Quantum mechanics, particle physics (defects, gauge structure, generations, mass patterns, mixing), dark matter identity (neutral defects), neutrino physics (delocalized defects). The framework remains a viable theory of non-cosmological physics.

### 5.3 Case: Weak Deviation (w ≈ −0.98 ± 0.02, Level B)

**Action: No immediate revision.**

1. The evidence is consistent with the prediction but at marginal significance.
2. Wait for Roman Space Telescope data to reduce uncertainty to σ ≈ 0.01.
3. If Roman confirms the deviation at >3σ → Model Update (refine Λ(t) parameters).
4. If Roman finds w = −1.00 ± 0.01 → escalate to Case 5.2 (Sector Replacement).

### 5.4 Case: Strong Deviation with Correct Sign (Level C-D, w ≠ −1)

**Action: Model Update.**

1. The Λ(t) hypothesis survives its most critical test.
2. Refine the specific functional form and the dimensionless coefficient using measured data.
3. The framework is not "confirmed" — other models also predict w ≠ −1. Distinguishing tests remain necessary.

## 7. Parameter Revision Protocol

### 7.1 The M² = ⟨k⟩ Claim

**Prediction:** M² = ⟨k⟩_interact ≈ 5. The single continuous parameter is eliminated; the framework has zero free parameters (XC002-XC005).

### 7.2 Possible Outcomes

| Finding | Significance | Action |
|---------|:--:|--------|
| M² = ⟨k⟩ confirmed (precise match) | Analytical proof | **No revision.** Zero-parameter claim validated. |
| M² ≈ ⟨k⟩ within factor ~1.5 | Current status | **No revision.** Consistent with current precision. |
| M² ≠ ⟨k⟩ (no consistent definition matches) | Proof | **Model Update.** Accept M² as a measured input. Framework becomes one-parameter. Compression ratio ~95% still applies. |
| ⟨k⟩ shown to depend on ρ (density) | Proof | **Model Update.** The analytical ρ-cancellation proof (XC004) is wrong or the assumptions don't hold. M² remains a free parameter. |

### 7.3 Is One Parameter Acceptable?

Yes. The framework's value does not depend on whether the parameter count is exactly zero or one. A one-parameter framework achieving ~95% compression from the Standard Model's ~19 parameters is a significant scientific achievement. The difference between zero and one is philosophically interesting but scientifically minor — both represent massive compression.

**The zero-parameter claim is aspirational, not definitional.** Revision to one parameter does not constitute failure.

## 8. Framework Retirement Criteria

### 8.1 Mandatory Retirement

The framework must be retired under any of the following conditions:

**Condition R1: Tier 1 Internal Contradiction.** An independent researcher demonstrates a logical error in the derivation of quantum mechanics (X036-X037), time (X040), or spacetime dimensionality (X042) from the Tier 0 axioms. If the derivation is invalid, the entire structural layer collapses. The framework cannot survive this.

**Condition R2: Cumulative Predictive Failure.** All Tier 4 predictions fail at Level C or above, and no replacement sector produces new testable predictions within 5 years. A framework with no surviving predictions is not scientific.

**Condition R3: Occam Defeat.** A competing framework is published that:

- Has strictly fewer primitives (1 or 0 versus TQM's 2).
- Makes the same or more testable predictions.
- Is consistent with all current data.
- Is independently verified by researchers outside the TQM collaboration.

**Condition R4: Empirical Exclusion.** An experiment demonstrates a phenomenon that is impossible under TQM's axioms — for example, a demonstration that distinguishable entities do not have integer-valued topological invariants, or that quantum randomness is deterministic. This is unlikely but would constitute direct falsification of the primitives.

### 8.2 Discretionary Retirement

The collaboration may vote to retire the framework if:

- Active researchers in the program fall below 3 for more than 24 months.
- No new testable predictions have been generated for 5 years.
- The framework's predictions have been consistently disconfirmed across multiple sectors, even if individual predictions survive.

### 8.3 What Survives Retirement

Even if the framework is retired, the following components may be preserved as standalone contributions to mathematical physics:

- The identity/abundance distinction as a classification of physical quantities.
- The defect topology → gauge symmetry correspondence.
- The causal set connectivity → dimensionality relation (XC004 — ρ cancellation proof).
- The multiplicative cascade → log-normal abundance distribution mechanism.
- Computational tools and simulation frameworks developed during the program.

## 9. Framework Preservation Criteria

### 9.1 Conditions for Continued Viability

The framework remains viable — and should continue to be developed — under any of the following conditions:

**Condition P1: Core Intact.** At least one major prediction (Tier 4) survives experimental testing at Level C or better, AND no Tier 1 contradiction has been demonstrated. Even a single surviving prediction (e.g., neutrino normal ordering) justifies continued investigation of the framework.

**Condition P2: Explanatory Compression Maintained.** The framework continues to compress the Standard Model's parameter count by >90% (>17 of ~19 parameters eliminated). Even if some predictions fail, the explanatory economy may justify continued development.

**Condition P3: Novel Predictions Generated.** The framework generates at least one new testable prediction (not in the original XD001 catalog) within any 5-year window. A living framework produces new predictions.

**Condition P4: Experimental Program Active.** At least one experiment specifically testing a TQM prediction is actively taking data or under construction. A framework without an experimental program is philosophy, not physics.

### 9.2 Preservation Under Partial Failure

The framework is designed to survive partial failure. The following failures are survivable:

- **Complete cosmology sector failure.** The framework becomes a theory of quantum mechanics, particles, and gravity.
- **Dark matter identity failure.** The defect ontology survives; a new DM candidate is sought.
- **Abundance distribution failure.** The identity/abundance distinction survives as a conceptual framework.
- **M² elimination failure.** The framework becomes one-parameter — still significant compression.

The only unsurvivable failures are Tier 1 internal contradiction (Condition R1) and cumulative failure of all testable predictions (Condition R2).

## 12. Living Framework Model

### 12.1 Evolution 2025–2035

The framework is expected to evolve through three phases:

**Phase 1: Anticipation (2025–2027).** All predictions are live. No experimental results have reached decisive significance. The collaboration focuses on: refining internal derivations, closing known open problems (Section 9, Failure Analysis Framework), and preparing analysis pipelines for Euclid, JUNO, and Rubin/LSST data.

**Phase 2: Falsification Window (2027–2032).** Euclid, JUNO, and Rubin/LSST produce first results. The collaboration executes the decision matrix (Section 10) without deviation. Failed predictions are revised or replaced according to protocol. Successful predictions are documented and refined.

**Phase 3: Revision or Consolidation (2032–2035).** Depending on Phase 2 outcomes, the framework either (a) undergoes substantial revision (replaced sectors, modified predictions) or (b) consolidates around surviving predictions and generates new ones. A comprehensive review at the end of Phase 3 determines whether the framework continues, is revised, or is retired.

### 12.2 Stable Core vs Revisable Periphery

The following components are considered **stable** — revision requires Level D evidence or internal contradiction:

- Tier 0: Q, Randomness.
- Tier 1: QM emergence, time from actualization, 3+1 dimensions.

The following components are **revisable** — Model Update or Sector Replacement is expected if contradicted:

- Tier 2: Specific defect identifications (which defect = which particle). The broader defect ontology (particles = defects) is more stable than specific identifications.
- Tier 3: Quantitative abundance framework. The qualitative identity/abundance distinction is stable.
- Tier 4: All specific predictions. These are designed to be falsifiable. They may be revised or replaced.

## 13. Final Governance Principle

The following single principle governs all revision decisions:

> **Preserve the deepest layer compatible with the evidence.**

If a prediction fails, retreat to the tier above it. If that tier's predictions also fail, retreat further. The framework's survival boundary is Tier 1 — if the structural layer is internally consistent and logically derived from Tier 0, the framework retains value regardless of how many higher-tier predictions fail.

Conversely, if Tier 1 contains a logical error, or if a competing framework achieves greater explanatory compression with fewer primitives, the framework should be retired regardless of its internal beauty or the effort invested in it.

This principle ensures that TQM behaves as a scientific framework, not a belief system. It is designed to be wrong in places — and to have a procedure for discovering exactly where.
