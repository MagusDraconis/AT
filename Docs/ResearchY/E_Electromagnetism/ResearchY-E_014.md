## The question

What **selects** the flux sector label `n`? **Known:** `n` **exists**, `n` is **quantised**, `n` **survives
refinement**. **Unknown:** why `n != 0`? Candidates: **boundary conditions**, **topological constraints**,
**actualization process**, **initial conditions**, **occupancy arrangement**. Goal: locate the **origin of sector
occupation**.

## The answer: **BOUNDARY - and the negative is proved rather than declared**

> The family is generated by **one operation**, no AT law depends on the sector, the constraint permits **every**
> value, and no operation of the configuration space takes a non-zero label to zero. So **"why n != 0" has exactly the
> same status as "why n = 0": neither is selected.**

## 1. The label, and the one operation that generates the family

| quantity | value |
|---|---|
| label at L = 8 / 16 / 32 / 64, n = 1 | **1, 1, 1, 1** |
| strength at L = 8 / 16 / 32 / 64 | 0.785398, 0.392699, 0.196350, 0.098175 (**8x** across the range) |
| vacuum to sector series | **0 -> 1 -> 2 -> 3** |
| shift moves the label by | **1** |
| phase periodicity residual | **2.449E-016** (the real field: **6.283**, *not* periodic) |
| shift invertibility residual | **0.000E+000** |
| uniformity residual | **8.882E-016** |

Adding one quantum of uniform field - `A_1 -> A_1 + (2 pi / L) y` - is a legitimate change of a **compact phase**,
and it moves the label by exactly one.

**A note on the reading.** The label is taken from the **reduced** plaquette, so the seam cell is read as the same
phase as every other cell: without that reduction a uniform sector *looks* non-uniform at the wrap-around (**1.257E+001**
before the fix). It is the same seam E_012 and E_013 each had to handle, caught here by the audit's own uniformity
check.

At machine precision for **every** integer tested, at **every** lattice size: the constraint that **forbids** the

## 4. No operation collapses a non-zero label to zero

| operation | label produced from n = 1 |
|---|---|
| identity | 1.000000 |
| translate x -> x + 1 | 1.000000 |
| translate x -> x + 3 | 1.000000 |
| reflect y -> L - 1 - y | **-1.000000** |
| negate the configuration | **-1.000000** |

Translation **preserves** the label; reflection and negation **reverse its sign** (the orientation is reversed).
**Nothing produces zero.**

## Verdict

**BOUNDARY.** The origin of sector occupation is an **external assignment**. AT derives the **label** and its
**quantisation**; the **occupation** is a boundary. The verdict has a **live branch**: a single sector-dependent law
anywhere in AT would move it to **DERIVED**.
