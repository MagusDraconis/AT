## Purpose

NP_116 established meaning = value-weighted prediction (significance). NP_117 asks the final
teleological question: **what is purpose, and how does it differ from meaning?** Program: (1) define
meaning / value / choice / decision / purpose; (2) determine whether purpose is weighted meaning /
selected prediction / future-oriented actualization / stable value hierarchy; (3) remove value; (4)
remove prediction; (5) determine what survives; (6) trace observer → meaning → purpose → action; (7)
determine whether purpose changes future actualization. **Success criterion:** the ontology of
purpose, distinguished from meaning. No new primitives; canonical AT unchanged.

---

## 1. Define the five terms

| Term | In AT |
|---|---|
| **meaning** | value-weighted prediction (the significance, NP_116) |
| **value** | the weight — a distinction's consequence for the observer's future |
| **choice / decision** | the selection — the observer picks among weighted predictions |
| **purpose** | the SELECTED prediction — the chosen aim (a stable value hierarchy) |
| **action** | the future actualization the purpose aims toward |

**Purpose is meaning PLUS selection**: meaning weighs, purpose *aims*.

---

## 2. A / B / C / D — what is purpose?

| Interpretation | Verdict |
|---|---|
| **A) weighted meaning** | **NECESSARY, not sufficient.** Purpose is weighted, but it adds a direction (selection). |
| **B) selected prediction** | **YES — the differentiator.** Purpose is the prediction the observer SELECTS as its aim. |
| **C) future-oriented actualization** | **YES — the same object.** Purpose is oriented toward future actualization. |
| **D) stable value hierarchy** | **YES — the same object.** Purpose is the stable hierarchy of values that selects the aim. |

**Determination: B = C = D (selected prediction = future-oriented actualization = stable value
hierarchy); A (weighted meaning) is necessary but not sufficient.** The differentiator from meaning
is *selection* (direction).

---

## 3. Remove value

**Purpose and meaning both collapse.** Value is the weight; without it there is no significance
(no meaning) and no selection criterion (no purpose). Information, knowledge, and understanding
survive — the predictive machinery without the weighting.

---

## 4. Remove prediction

**Purpose collapses; meaning collapses; knowledge and understanding collapse.** Without prediction
there is no future to aim at and no significance to weight. Only information (raw) survives.

---

## 5. What survives?

| Removed | Survives | Gone |
|---|---|---|
| value | information, knowledge, understanding | **meaning, purpose** |
| prediction | information (raw) | **meaning, purpose**, knowledge, understanding |

**Purpose is the most dependent** — it needs value (to select) AND prediction (to aim) AND meaning
(the weighted prediction to select from).

---

## 6. Observer → meaning → purpose → action

```
observer (reads distinctions, NP_111)
   → meaning (the significance, NP_116)         [weighs]
      → purpose (the selected aim, NP_117)       [aims]
         → action (the future actualization)      [does]
```

The chain is **cumulative and directional**: meaning weights, purpose selects a direction, action
executes. Purpose is the bridge from significance to doing.

---

## 7. Does purpose change future actualization?

**YES — this is the point.** Purpose IS the selection of a future direction, so it *directs* the
observer's subsequent actualizations: the observer acts toward the selected aim. Purpose is what
makes meaning *operative* — it converts significance into a goal that shapes what happens next.

## 8. Counterexamples

| Attempt | Why it fails |
|---|---|
| "purpose = meaning" | meaning weighs; purpose selects a direction (aims) |
| "purpose = prediction" | a prediction is not selected; purpose is the chosen aim |
| "purpose survives without value" | no weight = no selection criterion = no aim |
| "purpose needs a new primitive" | purpose is meaning + selection, both derived |
