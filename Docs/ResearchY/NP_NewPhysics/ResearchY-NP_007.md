## Purpose

**Does Actualization define a coupling field between distinguishable states?** NP_003–
NP_006 established that the phase is the only local lever, that coupling exists via
interference, and that the locking coefficient κ = 2√(ρ_Aρ_B) is Born-derived. This
audit asks whether interactions emerge from a NETWORK/FABRIC structure — a coupling
field between states — rather than from isolated states acting independently.

## 4. The hidden interaction term already in the network

For any two states A (ρ_A) and B (ρ_B) in superposition, the interference intensity is:

```
I = ρ_A + ρ_B + 2√(ρ_Aρ_B)·cos(θ_A − θ_B)
```

The cross-term 2√(ρ_Aρ_B)·cos(θ_A−θ_B) IS the link: it couples the two states'
phases observably, and its amplitude IS the coupling coefficient:

```
κ = 2√(ρ_Aρ_B)
```

**This is the HIDDEN interaction term already present in the actualization network.**
It is not introduced externally — it is the Born cross-amplitude of the complex-state
structure (D_036 + QG216), and its value is fixed by the state amplitudes.

## 5. Analysis: count flow, phase flow, information flow, reciprocity

| Flow | Present in canonical network? |
|---|---|
| **count flow** | YES — Born redistribution (M_005) conserves Σρ = 1 |
| **phase flow** | NO — no cross-phase term in the evolution (NP_005) |
| **information flow** | YES — measurement redistributes information (M_005) |
| **reciprocity** | YES — the read is symmetric (D_037); the link is bidirectional |

**The network carries count and information flow and is reciprocal, but carries NO
phase flow.** The coupling coefficient κ = 2√(ρ_Aρ_B) is a LINK WEIGHT in this network.

---

## 6. Can κ emerge from network structure?

**YES — κ = 2√(ρ_Aρ_B) is the network link weight, derived from the state amplitudes
(Born cross-amplitude).** It is not an external parameter: any two states with
amplitudes ρ_A, ρ_B have a link of weight 2√(ρ_Aρ_B). The "coupling field" is the
interference network of the complex state space — a fabric of links, each with
Born-derived strength.

**But the network alone does NOT produce synchronization** (NP_005): the links carry
no phase flow, so the canonical evolution remains local and unequal modes drift.

## 7. Tests: shared actualization, shared links, common phase structure, collective modes

| Structure | Result |
|---|---|
| **shared actualization** | pins both phases (M_002); link is observable at the read |
| **shared links** | the interference network links any superposed pair |
| **common phase structure** | the complex-state space gives every pair a relative phase |
| **collective modes** | in-phase (rel=0): I = (√ρ_A+√ρ_B)² = max; anti-phase (rel=π): I = (√ρ_A−√ρ_B)² = min |

**Collective modes are the network's observable signatures** — verified: ρ_A=0.25,
ρ_B=0.75 gives in-phase I = (0.5+0.866)² = 1.866, anti-phase I = (0.5−0.866)² = 0.134.

## Theorem

> **Theorem (NP_007).** Actualization defines a static COUPLING NETWORK (a link
> structure) between distinguishable states, but NOT a propagating field. Proof:
> (1) The complex-state space (D_036, D_039) with the Born rule (QG216) gives, for any
> two superposed states, the interference intensity I = ρ_A+ρ_B+2√(ρ_Aρ_B)·cos(θ_A−θ_B).
> (2) The cross-term is a LINK: it couples the two phases observably, and its amplitude
> κ = 2√(ρ_Aρ_B) is the coupling coefficient — a network link weight derived from the
> state amplitudes, not an external input (verified: κ = 2√(0.25·0.75) = 0.866).
> (3) The link is bidirectional (reciprocity, D_037) and carries count and information
> flow (M_005) but NO phase flow (the canonical evolution is local, self-rate only,
> D_041/NP_005). (4) Therefore Actualization creates link-mediated influence (B) and
> collective modes (in-phase/anti-phase superpositions), but no field-like propagation
> (C) and no synchronization of unequal modes. The coupling coefficient κ emerges from
> the network structure (Born cross-amplitude) — it is the state-space fabric, not an
> external coupling field. Classification: the link structure (interference cross-term)
> is DERIVED (complex state D_036 + Born QG216); the link weight κ = 2√(ρ_Aρ_B) is
> DERIVED; reciprocity EMERGENT (D_037); collective modes DERIVED (superposition
> algebra); a propagating coupling field is BOUNDARY (absent from canonical AT). No new
> primitive; canonical AT unchanged.
>
> *Proof sketch.* (1) Exhibit the interference link (Section 4, verified numerically).
> (2) Show κ is the network weight (Sections 4–6). (3) Show no phase flow — the network
> is static (Section 5, NP_005). (4) Exhibit collective modes (Section 7, verified:
> in-phase 1.866, anti-phase 0.134). ∎

## 8. Necessity Proof

The link structure is NECESSARY for any observable coupling: without the interference
cross-term, two states' relative phase is unobservable (D_037: a alone ambiguous) and
no collective mode exists. The network is the minimal fabric that makes relative phase
observable — and its weight κ = 2√(ρ_Aρ_B) is the same coefficient NP_005/NP_006
showed is necessary for synchronization. The network provides the coefficient; it just
does not (yet) provide the phase flow that would make it dynamical.

## 10. Falsification Path

1. **Link-structure claim** — falsified if two superposed states show NO interference
   cross-term (no relative-phase dependence of intensity): the network would be absent.
2. **Static-network claim** — falsified if a propagating (delayed, spatial) coupling is
   observed with no added structure: that would require a field the canonical chain
   does not contain.
