## Purpose

NP_126 established resonance sailing = radiation pressure. NP_127 asks the broader engineering
question: **what useful technologies become possible if matter is fundamentally a bound resonance
structure?** Program: (1) inventory resonance propagation / locking / scattering / sailing; (2)
search for engineering leverage (coupling / coherence / phase locking / mode selection); (3)
determine whether new technology arises from enhanced coupling / reduced scattering / coherence
preservation / controlled phase locking; (4) evaluate applications (propulsion / communication /
sensing / energy / materials); (5) reject concepts violating momentum conservation / causality /
thermodynamics. **Success criterion:** identify physically allowed technology concepts uniquely
suggested by the Difference → Resonance ontology. No new primitives; canonical AT unchanged.
