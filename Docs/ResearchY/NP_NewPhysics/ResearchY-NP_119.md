## Purpose

NP_118 established choice = the act of selecting. NP_119 asks the culminating agential question:
**what is freedom, and how does it differ from choice and randomness?** Program: (1) define
alternative / choice / freedom / constraint; (2) determine whether freedom is number of alternatives
/ unconstrained choice / capacity to select among meanings / actualization under incomplete
determination; (3) remove alternatives / values / purpose; (4) determine what survives; (5) compare
forced / random / chosen action; (6) determine whether freedom is derived / emergent / boundary; (7)
test compatibility with Born selection, actualization, Difference conservation. **Success
criterion:** the ontology of freedom, distinguished from choice and randomness. No new primitives;
canonical AT unchanged.

---

## 1. Define the four terms

| Term | In AT |
|---|---|
| **alternative** | a possible future actualization (an option) |
| **choice** | the act of selecting (NP_118) |
| **freedom** | the CAPACITY to select among meanings — actualization under incomplete determination |
| **constraint** | the value hierarchy + purpose that weights the selection |

**Freedom is not unconstrained — it is value-constrained.** It is the capacity to choose among
value-weighted predictions (meanings), toward a purpose, under incomplete determination.

---

## 2. A / B / C / D — what is freedom?

| Interpretation | Verdict |
|---|---|
| **A) number of available alternatives** | **PARTIAL — a precondition.** More alternatives is a *condition* of freedom, not freedom itself. |
| **B) degree of unconstrained choice** | **REFUTED.** Freedom is NOT unconstrained — it is value-constrained (weighted by meaning). |
| **C) capacity to select among meanings** | **YES.** Freedom is the capacity to select among value-weighted predictions (meanings). |
| **D) actualization under incomplete determination** | **YES — the answer.** Freedom is the Born-weighted actualization whose outcome is not predetermined but weighted. |

**Determination: C = D (capacity to select among meanings = actualization under incomplete
determination); A is a partial precondition; B (unconstrained) is refuted.**

---

## 3. Remove alternatives / values / purpose

| Removed | Result |
|---|---|
| **alternatives** | freedom collapses — forced (deterministic) |
| **values** | freedom collapses — random (a raw Born draw, NP_093) |
| **purpose** | freedom collapses — prediction, not freedom |

**Freedom needs all three** — alternatives (to select among), values (to select by), purpose (to
select toward). Remove any one and it degenerates into either determinism (forced) or randomness.

---

## 4. What survives?

**Raw actualization (the Born draw) survives — but that is randomness, not freedom.** Freedom is not
the substrate (actualization); it is the *structured* selection — actualization weighted by meaning
and aimed by purpose. Remove the structure and only the draw remains.

---

## 5. Forced / random / chosen action

| Action | Alternatives | Values | Purpose | What it is |
|---|---|---|---|---|
| **forced** | none | — | — | deterministic (no freedom) |
| **random** | yes | none | none | a Born draw (no freedom) |
| **chosen** | yes | yes | yes | **freedom** |

**Freedom is the middle path** between determinism (forced) and randomness (random): it is the
value-weighted, purpose-directed selection under incomplete determination.

## 6. Derived / emergent / boundary?

| Component | Status |
|---|---|

| the value/purpose structure (meaning, NP_116/117) | **EMERGENT** |

**Freedom is EMERGENT**, built on the BOUNDARY stochasticity of the tick and the EMERGENT value
structure.

---

## 7. Is freedom compatible with Born selection, actualization, Difference conservation?

**YES — freedom IS these things.** Freedom is exactly the Born-weighted selection (NP_093) under
incomplete determination: the weight is the *value* (meaning, NP_116), the draw is the irreducible
*stochasticity of the tick* (NP_107). It does not violate Difference conservation (NP_105) — freedom
is *selection*, not *creation*: it chooses among the existing alternatives, it does not create new
distinctions. Freedom is therefore **compatible by identity** with the theory's foundations.

| "freedom = unconstrained choice" | freedom is value-constrained (weighted by meaning, NP_116) |
| "freedom = determinism" | the outcome is not predetermined — it is under incomplete determination (the tick) |
| "freedom violates Difference conservation" | freedom is selection, not creation (it chooses among existing alternatives) |
| "freedom needs a new primitive" | freedom IS Born selection + value + purpose, all derived |
