## Purpose

NP_122 completed the experiential arc with consciousness. NP_123 asks the epistemic-normative
question: **what is truth, and how does it differ from knowledge, understanding, and meaning?**
Program: (1) define belief / model / prediction / truth / error; (2) determine whether truth is
successful prediction / model-network correspondence / stable distinction mapping / persistence
across observations; (3) remove prediction / observation / consistency; (4) determine what survives;
(5) compare true / useful / false model; (6) trace observation → knowledge → understanding → truth;
(7) find the minimum condition for truth. **Success criterion:** the ontology of truth, distinguished
from knowledge, understanding, and meaning. No new primitives; canonical AT unchanged.

## 1. Define the five terms

| Term | In AT |
|---|---|
| **belief** | a held distinction in the observer's model |
| **model** | the observer's integrated distinctions (NP_115) |
| **prediction** | the model's anticipation (NP_114) |
| **truth** | the CORRESPONDENCE between the model's distinctions and the world's persistent structures |
| **error** | a failure of that correspondence (a contradiction) |

**Truth is correspondence, not success.**

---

## 2. A / B / C / D — what is truth?

| Interpretation | Verdict |
|---|---|
| **A) successful prediction** | **NECESSARY, not sufficient.** A prediction can succeed by luck; "useful" ≠ "true". |
| **B) model-network correspondence** | **YES.** Truth is the model mapping to the network's persistent structures. |
| **C) stable distinction mapping** | **YES — the answer.** Truth is the stable mapping of the model's distinctions onto the world's. |
| **D) persistence across observations** | **YES — the same object.** Truth is the mapping not contradicted by observation. |

**Determination: B = C = D (model-network correspondence = stable distinction mapping = persistence
across observations); A (successful prediction) is necessary but not sufficient.**

---

## 3. Remove prediction / observation / consistency

| Removed | Result |
|---|---|
| **prediction** | truth PARTIALLY survives — a static map can correspond (be true) without predicting |
| **observation** | truth COLLAPSES — no model is built to correspond |
| **consistency** | truth COLLAPSES — a contradictory mapping is false |

**The crux is CORRESPONDENCE** — not prediction (a true map need not predict) and not mere
observation (which builds the model but does not make it true).

---

## 4. What survives?

Remove prediction → **truth survives** (correspondence is independent of prediction); remove
observation or consistency → **truth collapses**. This is the decisive point: truth is the *mapping*
between model and world, not the *success* of prediction.

---

## 5. True / useful / false model

| Model | What it is |
|---|---|
| **true** | its distinctions MAP to the world's persistent structures (corresponds) |
| **useful** | its predictions SUCCEED (pragmatic — may or may not correspond) |
| **false** | its distinctions are CONTRADICTED (do not map) |

**True ≠ useful**: a convenient fiction (a "useful" model) can predict well while failing to
correspond — it is useful but not true. Truth is correspondence, the pragmatic criterion is success.

---

## 6. Observation → knowledge → understanding → truth

```
observation (incorporate, NP_113)
   → knowledge (predict, NP_114)
      → understanding (model of models, NP_115)
         → truth (correspond, NP_123)   [the mapping to the world]
```

Each step adds a condition: incorporate → predict → model → **correspond**. Truth is the final step,
where the model is checked against the world's persistent Difference structures (which pre-exist,
M_005 — so the correspondence is well-defined, structure-relative, NP_112).

---

## 7. The minimum condition for truth

**CORRESPONDENCE (the stable distinction mapping).** A model is true exactly when its distinctions
map onto the world's persistent Difference structures — when the model's "this" and "that" match the
world's "this" and "that". Prediction success is a *symptom* of correspondence, not the truth itself;
and the mapping must be *consistent* (a contradictory mapping is false).

| "truth = meaning" | meaning is value-weighting; truth is correspondence (value ≠ correspondence) |
