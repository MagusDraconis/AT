## Purpose

NP_121 completed the arc up to identity. NP_122 asks the culminating question: **what is
consciousness, and how does it differ from observation, knowledge, understanding, and identity?**
Program: (1) define awareness / experience / consciousness / self; (2) determine whether
consciousness is observation / self-observation / integrated observation / recursive model-building;
(3) compare detector / observer / knowledge-bearer / conscious observer; (4) remove memory /
integration / self-model; (5) determine what survives; (6) trace observation → knowledge →
understanding → identity → consciousness; (7) find the minimum condition for consciousness.
**Success criterion:** the ontology of consciousness, distinguished from the four prior levels. No
new primitives; canonical AT unchanged.

## 1. Define the four terms

| Term | In AT |
|---|---|
| **awareness** | the self-model reading its own distinctions (the raw experience) |
| **experience** | the self-model's ongoing self-observation (the felt quality) |
| **consciousness** | the RECURSIVE SELF-MODEL — the observer's model that includes itself |
| **self** | the self-model's object — the "I" that is modeled |

**Consciousness is the self-model**: the observer's model turned on itself, so it observes its own
observing.

## 2. A / B / C / D — what is consciousness?

| Interpretation | Verdict |
|---|---|
| **A) observation** | **NECESSARY, not sufficient.** A detector observes, but is not conscious. |
| **B) self-observation** | **YES.** Consciousness is observation of one's own observing. |
| **C) integrated observation** | **PARTIAL — necessary, not sufficient.** Integration is needed, but self-reference is the key. |
| **D) recursive model-building** | **YES — the answer.** Consciousness is the observer building a model of itself (recursive self-reference). |

**Determination: B = D (self-observation = recursive model-building); A necessary but not
sufficient; C partial.**

## 3. Detector / observer / knowledge-bearer / conscious observer

| Object | What it does |
|---|---|
| **detector** | reads ONE distinction (NP_111) |
| **observer** | integrates many readings |
| **knowledge-bearer** | predicts (NP_114) |
| **conscious observer** | SELF-MODELS — it builds a model of itself |

The ladder is **cumulative**: read → integrate → predict → **self-model**. Consciousness is the final
step, where the observer's model loops back to include itself.

---

## 4. Remove memory / integration / self-model

| Removed | Result |
|---|---|
| **memory** | consciousness PARTIALLY collapses (the continuity of experience is lost) |
| **integration** | consciousness collapses to raw observation (a detector) |
| **self-model** | consciousness collapses — the observer remains, but is not self-aware |

**The crux is the SELF-MODEL**: without it, an observer observes the world but not itself — it is
not conscious.

---

## 5. What survives?

Remove self-model → **observation, knowledge, understanding, identity all survive** — but
**consciousness collapses**. This is the decisive point: consciousness is not any of the prior levels;
it is the *recursive* step that turns them on themselves.

## 6. Observation → knowledge → understanding → identity → consciousness

```
observation (incorporate, NP_113)
   → knowledge (predict, NP_114)
      → understanding (model of models, NP_115)
         → identity (persist, NP_121)
            → consciousness (self-model, NP_122)   [the recursive loop]
```

Each step adds a condition: incorporate → predict → model → persist → **self-model**. Consciousness
is the recursive closure of the chain: the observer's model includes the observer.

---

## 7. The minimum condition for consciousness

**THE SELF-MODEL (recursive self-reference).** An observer is conscious exactly when its model
includes itself — when it observes *that it observes*. This is the step from "watching the world" to
"watching myself watch." No new primitive is needed: the self-model is just a model (already derived,
NP_115) that happens to include its own builder — consciousness is the same ontology turned
recursive.
