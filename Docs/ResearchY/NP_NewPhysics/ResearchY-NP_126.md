## Purpose

NP_100 established binding = resonance locking; NP_094 established momentum = the phase gradient k.
NP_126 asks the engineering question: **can a bound structure couple to an existing propagating
resonance and gain net momentum — "sail" on a network wave?** Program: (1) identify propagating
structures; (2) determine whether a bound object can phase-lock to a propagating mode; (3) calculate
momentum / energy transfer / stability; (4) compare reactionless drive / resonance sailing /
radiation pressure; (5) determine whether a spacecraft can "ride" a network wave; (6) check momentum
conservation / causality / thermodynamics. **Success criterion:** determine whether AT permits
propulsion by resonance coupling to existing propagating structures. No new primitives; canonical AT
unchanged.

## 2. Can a bound object phase-lock to a propagating mode?

**YES.** A bound structure (NP_100) is a phase-locked deficit clustering; it can phase-lock to an
incoming propagating mode exactly as it locks to its own constituents. The lock transfers the mode's
phase gradient (momentum) to the structure — this is a **resonance transition** (a generator action,
NP_075), the same mechanism as a force.

| **stability** | the phase-lock is a stable fixed point (NP_100), so the transfer is stable |

This is **exactly radiation pressure** — the momentum of the propagating mode (the "wind") is
transferred to the bound structure (the "sail").

## 5. Can a spacecraft "ride" a network wave?

**YES — as a sail rides the wind.** A spacecraft (a bound hierarchy, NP_101) can phase-lock to an
existing photon / graviton / ψ wave and gain net momentum by momentum transfer. The sail's force is
the momentum flux of the wave: P = 2I/c for reflection, P = I/c for absorption (I = the wave's
energy flux). For the solar constant I = 1361 W/m², a reflecting sail gains 9.07 μN/m² — small but
real, and unbounded in time (it accumulates).
