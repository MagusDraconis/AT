# ResearchY — Wave Geometry Program

**Program:** ResearchY
**Title:** Wave Geometry Program
**Status:** ACTIVE — research and audit only
**Started:** 2026-08-28
**Version:** 2.1 (research track, non-canonical)

## Purpose

Investigate whether **Difference, Actualization, Spectrum, resonance, circular closure,
π, 2π, center, source, and wave propagation** are connected within the canonical AT
framework — as an explanatory and derivational audit of the canonical hierarchy

```
Difference → Actualization → Inevitable Spectrum → Physics
```

The program tests whether the canonical mathematics already contains the wave vocabulary
(localized disturbances, propagation, standing waves, radius, circumference, wavelength,
frequency, resonance) and whether circular closure can account for π and 2π.

## Rules

- Do **NOT** modify canonical AT V2.0.
- Do **NOT** introduce new primitives.
- Do **NOT** introduce ad-hoc constants.
- Treat all work as **research and audit only**.
- Record **assumptions explicitly** in every investigation.
- Check consistency against the canonical hierarchy
  Difference → Actualization → Inevitable Spectrum → Physics.
- Maintain a **hierarchical index** (see `ResearchY_Index.md`).
- No investigation may claim to change an observable, an equation, or a claim status of
  canonical AT.
