## Purpose

Determine whether **2π can emerge as a closure invariant without deriving π itself**,
and classify the result as **DERIVED, EMERGENT, or BOUNDARY**.

## Input (from B_002)

> Finite D96 graph ⇒ algebraic spectrum ⇒ no exact transcendental π.

If π's *value* cannot be derived, can the *full-cycle constant* 2π still emerge as an
invariant of closure?

---

## Test: four closure mechanisms

1. **Cycle closure.**
2. **Phase periodicity.**
3. **Eigenmode rotations.**
4. **N = 96 symmetry.**

---

## 1. Cycle Closure

A closed ring of N = 96 sites has a rotation R (one site). Closure means **R^N =
identity**: N rotations return to the start. This is an *algebraic* statement — the ring
is finite, so iterating the rotation must eventually return to the identity. No value of
π enters.

- The full-cycle period (in *site steps*) is N = 96 — an integer, exact.
- The statement "the cycle closes" is DERIVED (a finite-group fact).

## 2. Phase Periodicity

The state-phase lattice θ_k = 2πk/N (Ch9) is periodic: θ_{k+N} = θ_k. The phase is a
periodic function of the cycle, and **a minimal positive period exists** (periodic
functions have a fundamental period). The closure condition is

```
θ_{k+N} ≡ θ_k  (mod the full cycle)
```

which is equivalent to "the full cycle is the minimal positive period". The *existence*
of the full cycle is structural; its *numerical value in radians* (2π) is a unit
convention (radian measure).

## 3. Eigenmode Rotations

The eigenmodes of the circulant are φ_k(n) = e^{2πikn/N} (roots of unity). Under a
one-site rotation,

```
φ_k(n+1) = z_k · φ_k(n),   z_k = e^{2πik/N}.
```

After N rotations, the mode returns to itself: **z_k^N = 1** (verified numerically to
1e-12). The statement z_k^N = 1 is the *algebraic* root-of-unity closure — it is the
defining equation of the roots of unity and does not require the value of π. (The
parametrization z_k = e^{2πik/N} uses π as a *convention*; the content is z_k^N = 1.)

## 4. N = 96 Symmetry

The ring's dihedral symmetry D96 (rotations + reflections) is generated by the rotation
R and a reflection s. The closure of the rotation subgroup is R^N = identity (test 1);
the phase lattice closes at θ_N ≡ 0 (test 2); the eigenmodes are N-periodic (test 3).
All four mechanisms express the same algebraic fact: **the closed ring has a full cycle,
and the full cycle is invariant under the ring's symmetry.**

## Theorem

> **Theorem (B_003).** The full-cycle constant 2π emerges as a closure invariant of C96
> without deriving the numerical value of π.
>
> *Role:* the minimal positive phase period (the "full cycle") exists and is invariant
> under closure (cycle closure, phase periodicity, eigenmode rotations, N=96 symmetry).
> *Value:* the numerical value of the full cycle in radians is 2π = 6.283185…, which is
> transcendental and is a unit convention (radian measure) — it is not computed by the
> framework.

## Proof

1. C96 is a finite ring: the rotation R satisfies R^N = identity (N = 96, exact
   integer) — the cycle closes (Section 1).
2. The phase lattice θ_k = 2πk/N is periodic with a minimal positive period (Section 2).
   The closure condition θ_{k+N} ≡ θ_k is the statement that a full cycle exists.
3. The eigenmodes are roots of unity: z_k^N = 1 (verified numerically to 1e-12). The
   closure is the *algebraic* equation z^N = 1 (Section 3), which involves no value of π.
4. All four mechanisms reduce to the same algebraic closure (Section 4).

Hence the *existence and invariance* of the full cycle — the role of 2π — follows from
the finite/algebraic structure alone, with no transcendental value computed. The
*radian value* 2π = 6.283185… is a unit normalization that carries the transcendental
constant π (B_002); it is not derived.

## Research Conclusions

1. **2π emerges as a closure invariant without deriving π.** The full-cycle period is
   forced by the finite closed ring: R^N = identity, z_k^N = 1, θ_{k+N} ≡ θ_k — all
   algebraic statements that require no value of π.
2. **The value of 2π remains a boundary** (B_002: 2π = 2·π is transcendental).
3. **The radian normalization is a convention**: "the full cycle = 2π radians" assigns
   the number 2π to the structurally-emergent full cycle. The cycle exists; the number is
   a unit choice.
4. **Consistency:** B_001 (2π minimal phase closure — role), B_002 (π value boundary),
   and B_003 (2π role emergent, value boundary) form a consistent picture: the closure
   invariants are structural (emergent/derived), the transcendental values are boundary.
