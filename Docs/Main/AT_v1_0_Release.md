## 1. Scope

THE Q-MODEL (AT) compresses observable physics to a minimal primitive set —
$\{Q,\ \text{Random Actualization},\ (\ell,\tau,\hbar),\ M^2\}$ — and derives the *form*
of every structure (gauge groups, spatial dimensionality, the abundance law, the
multiplicity lower bound) while classifying the *content* (masses, couplings, the Koide
angle, multiplicities) as **contingent**. The governing principle is the
**structure/content split**: *structure is derivable, content is realized.*

This v1.0 release marks the **closure of the derivation and classification program** —
not a new derivation. Every in-scope question is now either **derived**, **closed
(underivable)**, **underdetermined (untestable)**, **contingent**, or **accepted as a
documented computational layer**.

## 6. Known Limitations

1. **The gauge-count face of the Internal-3 node is only provisionally closed** — T-09 is a
   weak no-go (0.10); the graph-spectrum and lattice-mode routes remain untested. This is
   the single most-tractable entry point for a future derivation.
2. **Encyclopedia is ~81% populated** — the CMB chapter is a documented *partial*
   computational layer (full $C_\ell$ solver deferred); this is accepted, not unresolved.
3. **Unified Action is a TRM roadmap, not a AT result** — it depends on vector/theta
   sectors that AT does not contain.
4. **The shared-cascade question is untestable** from one universe (T-12) — closure is
   logical, not empirical.
5. **Content is contingent** — specific masses, couplings, multiplicities, and the Koide
   angle are REAL-UNDERIVED / DRAWN, by construction of the structure/content split; this
   is a *feature* of the theory, not a gap.
