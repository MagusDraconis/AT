# Collective Charge Wave Theory

## TQM-126: Why Charge Modes Are Waves, Not Just Oscillators

### Abstract

We demonstrate that the collective mode field Θ(x,t) = Σ A_c·exp(iθ_c)
of multiple Q=+1 charges exhibits linear wave superposition with
cos(Δφ) amplitude modulation. This establishes that charge modes
are COHERENT WAVES, not merely synchronized oscillators.

### 1. The Collective Field

Define the collective mode field:

```
Θ(x,t) = Σ_c A_c(t)·G(x−x_c)·exp(i·θ_c(t))
```

where G is the spatial profile (Gaussian width ~0.08), A_c is
the amplitude of charge c's internal oscillation, and θ_c is its phase.

The squared modulus:

```
|Θ|² = Σ_c A_c²·G² + Σ_{c≠c'} A_c·A_{c'}·G(x−x_c)·G(x−x_{c'})·cos(θ_c−θ_{c'})
```

The **interference term** ∝ cos(Δθ) determines whether amplitudes
add constructively (Δθ≈0), destructively (Δθ≈π), or neutrally
(Δθ≈π/2).

### 2. The Wave Test

For two equal-amplitude charges at positions x₁, x₂:

```
|Θ(x)| = |A·[exp(iθ₁)·G(x−x₁) + exp(iθ₂)·G(x−x₂)]|
```

At the midpoint x = (x₁+x₂)/2 where G values are equal:

```
|Θ(mid)| = 2A·G·|cos(Δθ/2)|
```

This is the **cos(Δφ/2) test**: if |Θ(mid)| follows cos(Δφ/2)
as Δφ varies, charge modes exhibit linear wave superposition.

### 3. Wave-Synchronization Duality

| Aspect | Synchronization | Wave Interference |
|--------|----------------|-------------------|
| Phase dynamics | ∂Δθ/∂t → 0 (Adler) | Δθ fixed externally |
| Amplitude | A₁ ≈ A₂ (matched) | |Θ| = 2A·|cos(Δθ/2)| |
| Stability | Locking is attractor | Interference fades without locking |
| Long-term | Δθ → 0 (locking wins) | Requires Δθ to be maintained |

The tension: synchronization attracts Δθ→0, destroying the π phase
offset needed for destructive interference. Strong coupling favors
synchronization; weak coupling allows interference to persist.

### 4. Beats as Temporal Interference

When frequencies differ (Δω ≠ 0, unlocked):

```
|Θ(t)|² = 2A²[1 + cos(Δω·t)]
```

The amplitude oscillates at the beat frequency Δω. This is temporal
interference — the same cos(Δφ) physics in the time domain.

### 5. Conclusion

The cos(Δφ/2) amplitude modulation — with visibility up to 0.97 —
is the definitive signature of linear wave superposition. Charge
modes are coherent waves. The ensemble supports both particle-like
(Q∈ℕ, conserved) and wave-like (amplitude superposition, interference)
behavior simultaneously.
