# Topological Wave Quantum

## AT-124: Classical Wave-Particle Duality in Proto-Matter

### Abstract

AT-124 demonstrates that Q=+1 topological charge quanta are
simultaneously topological objects (conserved integer charge)
and coherent field excitations (internal phase oscillation at ω≈1).
This classical wave-particle duality enriches the proto-matter
framework without invoking quantum mechanics.

### 1. Two Independent Degrees of Freedom

The Q=+1 condensate has TWO independent properties:

**Topological Charge Q**:
- Q = β₀({R>0.5}) ∈ ℕ
- Conserved: dQ/dt = 0 (PDE barrier)
- Quantized: Q ∈ {0, 1, 2, ...}
- Created in integer units (kink-antikink pairs)

**Internal Phase θ**:
- θ(t) = θ₀ + A·sin(ωt) with ω ≈ 1
- Not conserved — oscillates freely
- Global phase rotation: R unchanged, Q unchanged
- Goldstone mode of U(1) phase symmetry

### 2. Why Spatial Modes Are Damped

The linearized PDE inside the condensate (R₀≈1):

```
∂(δR)/∂t = −2c₀·M·δR + D_R·∇²(δR)
```

Eigenfunction: φ_n(x) = sin(nπx/L)
Eigenvalue: σ_n = −2c₀·M − D_R·(nπ/L)² < 0

The negative eigenvalue means δR → 0 as t → ∞.
The condensate width is fixed by the reaction-diffusion balance.
Perturbations to the width are RESTORED — the condensate is STIFF.

Only the PHASE degree of freedom escapes this damping because
the PDE depends on phase DIFFERENCES, not absolute phases.

### 3. The Phase Mode

The Kuramoto dynamics produce natural oscillatory behavior:

```
dθ_i/dt = ω_i + (K/N)·Σ_j sin(θ_j − θ_i)
```

Inside a Q=1 condensate, all oscillators are phase-locked:
θ_i ≈ θ(t) for all i in condensate.

The mean phase θ(t) = ⟨θ_i⟩ oscillates at the mean frequency:
dθ/dt ≈ ⟨ω⟩ ≈ 1 rad/unit_time.

This is a COHERENT mode — all oscillators oscillate together.
It costs no energy (Goldstone mode). It does not change Q.

### 6. Implications

1. **Proto-matter is richer than topology alone.** Q tells us HOW MANY
   condensates exist. θ tells us their INTERNAL STATE.

2. **The topological charge is an EMERGENT macroscopic variable** that
   counts the number of synchronized oscillator clusters.

3. **The phase oscillation is the MICROSCOPIC remnant** of the original
   Kuramoto oscillators — synchronization produces Q, but oscillation
   persists within each Q.

4. **Classical wave-particle duality is not mysterious.** It simply means
   the same object has two independent sets of properties — one discrete
   (Q) and one continuous (θ).

### 7. Conclusion

Q=+1 is a TOPOLOGICAL WAVE QUANTUM: it carries a conserved integer charge
AND supports a coherent internal phase oscillation. This is a classical
analog of wave-particle duality, arising naturally from the Kuramoto
reaction-diffusion field theory. The charge quantum is simultaneously
particle-like (countable) and wave-like (oscillatory) — without any
quantum mechanical postulates.
