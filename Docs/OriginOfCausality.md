# Origin of Causality (QG-092)

Is causality truly fundamental, or can the causal order itself emerge from a deeper principle?

## The irreducible axioms
A causal partial order ≺ needs: transitivity, antisymmetry (acyclicity), and local finiteness.
Transitivity + antisymmetry ARE the order; local finiteness is the discreteness. Consistency can
forbid cycles (paradoxes) but cannot generate the order — the order must be given.

## Candidate deeper primitives — all fail
| candidate | can reconstruct causality? |
|---|---|
| Information | NO — distinctions already presuppose a relation |
| Computation | NO — computation is a causal sequence |
| Logic | NO — implication (→) is itself a partial order |
| Consistency | PARTIAL — forbids cycles but does not generate order |
| Mathematical relations | NO — circular (relation to explain relation) |
| Quantum correlations | PARTIAL — correlation ≠ order (ER=EPR still assumes an ordered boundary) |

## Conclusion
Causality is NOT derivable from a deeper primitive without circularity. It is the true
foundation. Fundamental vs emergent causality are observationally equivalent, so the causal-set
Λ ~ 1/√N prediction survives either way (it depends on the discreteness, not the origin of the
order). This is a terminus, not a new testable theory: the partial order is the bottom.

The full hierarchy: causality → time/change/geometry → cosmology (H, Λ ~ 1/√N).
