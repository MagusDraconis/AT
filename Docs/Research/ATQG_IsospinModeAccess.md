## Question

QG150 established that mode access is strongly isospin-constrained (r = 0.955): the down sector accesses
the full spectrum, the up sector the dense top band. This phase asks: **why does weak isospin select
different spectral regions?**

## Starting Point

## Method

The observable-sector spectrum is examined for a structural mechanism by which T3 selects a spectral
region. Five probes:

1. **Spectral-band selection** — the Z2 doublet structure of the mode groups.
2. **T3-dependent occupation** — the dense-band occupation of the T3 = +1/2 vs T3 = −1/2 channels.
3. **Octave accessibility** — down vs up effective-dimension accessibility.
4. **Mode competition** — the isospin splitting δ(up) − δ(down) as a golden-ratio fixed point.
5. **Sector-selection mechanism** — T3 as the guiding quantum number.

All probes are deterministic.

## Assumptions

1. The mode spectrum's degenerate groups (equal-frequency modes) are the weak-isospin doublets.
2. A sector's effective dimension δ_eff = p_eff/2 (QG149/150) determines which spectral region it couples
   to.
3. Two-channel mode competition has a self-similar fixed point at the golden ratio φ = (1+√5)/2.
