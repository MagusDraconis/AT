# Time-Scale Equations (QG-080)

- Two times: t (coordinate), τ (physical), γ(t)=dτ/dt.
- Static space: da/dτ = 0 in physical time; metric ds² = −c²γ²dt² + dℓ².
- Redshift: 1+z = γ_obs/γ_emit  (from frequency shift of a fixed physical clock).
- Time dilation: Δτ_obs = (γ_obs/γ_emit)·Δτ_emit.
- Distances: D_L = χ(1+z), D_A = χ/(1+z) (static χ + (1+z) energy/rate dilution).
- Identification γ=a ⇒ τ=conformal time η=∫a dt, and FLRW ds²=a²(η)[−dη²+dχ²+Sₖ(χ)²dΩ²].
- Hubble: H = (1/a)da/dt = (1/γ)dγ/dt = d(ln γ)/dt = τ̈/τ̇.
- g† = c·d(ln γ)/dt / 2π = c·(τ̈/τ̇)/2π = c·H/2π.
